## 📁 Cấu Trúc Thư Mục

```text
/
├── assets/
│   ├── css/                 # Các file stylesheet tùy chỉnh
│   ├── documents/           # Chứa các file bài tập PDF (Bài tập 1 đến bài tập tuần 6)
│   ├── images/              # Hình ảnh minh họa cho các nhiệm vụ (avatar, task1..6, poster...)
│   └── js/                  # Các file JavaScript (Tailwind config...)
├── .gitignore               # Cấu hình bỏ qua file cho Git
├── extracted_docs.txt       # Dữ liệu/tài liệu được trích xuất
├── index.html               # File trang chủ chính – single-page portfolio
└── README.md                # Tài liệu hướng dẫn này
```

## 🎯 Các Nhiệm Vụ (Tasks)

Portfolio trình bày chi tiết quá trình thực hiện 6 nhiệm vụ chính trong học phần:
- **Nhiệm vụ 1:** Quản Lý Tệp & Thư Mục
- **Nhiệm vụ 2:** Tìm Kiếm & Đánh Giá Thông Tin
- **Nhiệm vụ 3:** Viết Prompt Hiệu Quả
- **Nhiệm vụ 4:** Kỹ Năng Hợp Tác
- **Nhiệm vụ 5:** Sáng Tạo Nội Dung Với AI
- **Nhiệm vụ 6:** Đạo Đức AI
